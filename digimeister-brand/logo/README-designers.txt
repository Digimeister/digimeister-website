WHICH FILE
svg/mark/      production SVGs, large build — use at 48 px / 12.7 mm tall and above
svg/mark-small/   production SVGs, small build (no mouth, bigger eyes, heavier cable) — 20–47 px / 7–12.7 mm

svg/web/       live SVG with CSS variables (--ink, --paper, --cable) for the website and app; theme it, never edit it
png/         rasters at 1×/2×/4×, transparent except app icons and avatars
         png/app: app-icon-1024 (Paper field) · app-icon-dark-1024 · app-icon-on-signal-1024 · android-adaptive-foreground-1024 (transparent, 108 dp canvas with
         the icon in the 72 dp visible area; pair it with a flat Paper #F6F5F2 background layer) · app-icon-maskable-1024 (PWA, pair inside the 80 % safe circle) · social avatars · favicon.ico (16/32/48)

Production SVGs have no transforms, no strokes, no overlaps: 3 paths (ink, paper, signal) in the full-colour files, ONE path in the one-colour files.
Fill rule is evenodd. Open them in Illustrator/Figma/Inkscape as-is; nothing needs expanding or merging.

COLOUR SITUATIONS
 positive     Ink + Paper + Signal, for light backgrounds
 reversed     Paper + Ink + Signal, for dark backgrounds
 on-signal     Ink + Signal, for a #FFC01E field (the cable is Ink here — yellow on yellow would vanish)
 one-colour-*   a single colour: Ink, Paper, pure white or Signal. ANY one-colour process (copier, stamp, engraving, embroidery,
          laser, single-ink screen print) gets a one-colour file — never the colour file, whose Signal thresholds to white.
